Section E - Submit A Resource

Page Layout
The page should include:
A clear page title: Submit a Resource
A short explanation of what types of resources are accepted
Submission guidelines
An embedded Google Form 
A note explaining that submission does not guarantee inclusion
The page should use the same navigation, typography, colors, spacing, and responsive design as the rest of the website.
Introductory Description
The page should clarify that resources should be relevant to AMC 10, AMC 12, AIME, or advanced high school mathematics competitions.
Submission Form
The submission process will initially use a Google Form. Users will not need to create an account or sign in to the website.
The form should collect the following information:
Resource URL
Relevant subject
Number Theory
Geometry
Algebra
Combinatorics
Multiple subjects
Relevant topic or topics
Whether complete solutions are included
Optional submitter name
The topic and subject fields may use dropdowns, checkboxes, or multiple-choice selections to make submissions easier to review.


Submission Guidelines

Before submitting, users should be asked to confirm that:
The link works and is publicly accessible
The resource is relevant to contest mathematics
The resource is not already listed on the website
The resource comes from a credible source
The material is legally available to share
The description accurately represents the resource
Users should not submit pirated textbooks, paid materials uploaded without permission, broken links, unrelated advertisements, or low-quality resources.
The initial version of the website does not require an administrator dashboard or automatic publishing system.
Confirmation Message
After the form is submitted, users should see a confirmation message such as:
“Thank you for recommending a resource. Your submission will be reviewed before it is added to the website.”
Privacy

Future Enhancements
A future version may replace the Google Form with a custom submission form connected to a database and private administrator dashboard. This could allow the administrator to review, approve, reject, edit, and publish submissions directly without manually updating the website.
This functionality is outside the scope of the initial website release.
